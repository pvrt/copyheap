# CopyHeap для macOS

Нативная версия менеджера буфера обмена **CopyHeap** для macOS, написанная на **Swift и SwiftUI**.

## Особенности версии для macOS

- **Нативный интерфейс в Menu Bar (`NSStatusItem`)**: приложение работает в строке меню macOS без захламления Dock (`LSUIElement = true`).
- **Сквозная совместимость с Windows-версией**:
  - Полная поддержка формата истории и сниппетов (`history.json`).
  - E2E сквозное шифрование **AES-256-CBC** с деривацией ключа через **SHA-256** от персонального токена GitHub (через системный `CommonCrypto`).
  - Синхронизация с тем же секретным Gist `copyheap_backup` (`copyheap_pinned.json`), что позволяет бесшовно шарить сниппеты между Windows и Mac.
- **Интеграция с macOS Pasteboard**:
  - Автоматическое отслеживание текста из буфера обмена.
  - Фильтрация скрытых/временных парольных полей (1Password, Bitwarden и др.).
- **Окно поиска и управления сниппетами**:
  - Быстрый поиск по кириллице и латинице без учета регистра.
  - Закрепление, редактирование названий и содержимого, ручное создание сниппетов.
- **Ультралегкий вес**:
  - Единый скомпилированный бинарник ~720 КБ без тяжелых зависимостей (Electron/Chromium/Node).

## Требования

- macOS 13.0 (Ventura) или новее
- Apple Silicon (M1/M2/M3/M4) или Intel Mac
- Swift 5.9+ / Xcode Command Line Tools

---

## Сборка и запуск

### Быстрый запуск в режиме разработки:
```bash
cd macos
swift run
```

### Запуск тестов:
```bash
cd macos
swift test
```

### Сборка релизного бандла `.app`:
```bash
cd macos
./bundle.sh
```

Готовое приложение будет создано по пути:
`macos/build/CopyHeap.app`

Для переноса в систему:
```bash
cp -R macos/build/CopyHeap.app /Applications/
```

---

## Синхронизация через GitHub Gist

1. Нажмите на иконку CopyHeap в строке меню и выберите **«Синхронизация...»**.
2. Вставьте ваш [GitHub Personal Access Token](https://github.com/settings/tokens/new?scopes=gist&description=CopyHeap) с областью видимости `gist`.
3. Нажмите **«Синхронизировать сейчас»**. Все закрепленные сниппеты будут зашифрованы и сохранены в секретный Gist.
